# v3.2.10 · NFC 分块与等待修复

- 本机 v3.2.9 日志确认：手柄固件 1.1.5 能发现标签，并两次进入读取状态；随后收到 95 字节应答，被旧的固定分块校验拒绝。另一次停留在忙状态，约 1.2 秒就提前结束。
- 按应答中声明的数据长度解析分块并推进偏移，兼容可变分块和较长的传输帧；声明范围外的尾随字节不计入标签数据，与上游主动读卡器的处理一致。日志记录分块头、声明长度和尾随字节，便于核对实机的 95 字节应答格式。
- 读取忙状态使用 4 秒等待窗口；超时显示实际状态和详情，不再将仍在等待的操作笼统显示为“未进入读取状态”。
- 保留 600 字节缓冲边界、结束标志、UID、BCC 与 NTAG215 容量校验；截断、越界或身份不符的分块不会导出。
- 不改 FD2 输入订阅、连接间隔或 133Hz 请求；仍只通过既有主应答通道读卡。

使用：退出旧助手，用新版无线连接 Pro2，打开首页 **NFC 读卡…**，读取时将标签持续贴稳。

**只读实验，完整实卡导出仍待验证。** 95 字节实机帧目前只有总长度记录，新版补充详细分块头诊断。支持 NTAG215 文件导出；USB NFC、写卡、2KB 完整读取和游戏自动透传尚未接入。

验证：932035 项离线断言通过，包含可变分块、声明长度与尾随字节隔离、结束标志、超过 2 秒的忙状态、忙状态超时、移卡和停止清理。构建无警告、无错误；这些回放不代替完整实卡验收。
