# v3.2.5 · 新连接与重连提速

- 同一系统、蓝牙栈和适配器环境下，优先使用之前有效的连接方案。仍以本次真实 FD2 / Parsed 输入和间隙复核为准，不以缓存或 API 返回成功代替验收。
- 新连接和重连先做短窗口验收。真实输入已达到高速标准时，跳过完整的 10 秒预设轮测；没有通过时保留兼容测试与回退。
- Win10 复用已有系统蓝牙配置，普通重连不会再次提权或改写参数。Win11 使用当前设备连接参数请求，不套用 Win10 全局配置。
- 重连监听已知手柄的新鲜可连接广播，收到后可以立即结束扫描退避；不再由不可连接广播误触发完整重扫。多手柄地址隔离及未完成 GATT 请求保护保留。

实际连接时间仍受手柄广播、Windows 服务发现和驱动响应影响，不承诺固定秒数或所有硬件都达到 133Hz。高速判断采用真实输入，不重复发送旧状态提高显示数字。

已通过 931565 项离线断言、启动器测试和最终 EXE 界面启动检查。实机连接耗时与稳定性仍需测试，本轮未更改本机蓝牙参数。
