# v3.2.9 · NFC 前置检查修复

- 修复 Pro2 无线 NFC 测试在“无法确认 NFC 应答订阅状态”直接退出的问题。v3.2.8 本机三次均未发出 NFC 命令，不能据此判断手柄不支持读卡。
- 读卡复用现有主应答通道，取消对辅助 CCCD 的读取和改写；不切换 FD2 输入订阅、不改连接间隔。
- 日志补齐命令发送、API 写入结果、实际应答头、标签状态、分块偏移和失败位置；NFC 记录也保留到最近日志。
- 保留只读命令范围、取消、超时停止、分块校验，以及读卡前／期间／结束后的真实输入测速。

使用：退出旧助手，启动新版，通过 **Pro2 无线** 连接；首页 **NFC 读卡…** 选择对应手柄，点击读取并将 NTAG215 / amiibo 贴近手柄顶部 NFC 区。

**当前仍是只读实验。** 实体读卡尚待本版实测；不支持 USB NFC、写卡、完整 2KB 读取或游戏自动 NFC 透传。成功后可导出 540 字节数据，或另附 32 字节未认证的签名字段。

验证：931880 项离线断言通过，包含生产应答等待器的主通道读卡回放、其他设备／其他命令应答隔离、取消和失败清理，以及 NFC 最近日志保留检查。构建无警告、无错误；实卡读取结果仍待用户测试。
