# v3.3.0 · NFC 读卡与文件保存

- 首页 **NFC 读卡…** 保留为常规功能，支持选择 Pro2 无线槽位，读取 NTAG215 / amiibo。Pro1 蓝牙仍标为试验支持。
- 默认保存 **540 字节 .bin**；可选择附带收到的 32 字节签名字段，保存 572 字节文件。此选项不代表已完成原厂认证。
- 保存前复核长度和 UID/BCC，使用同目录临时文件完成写入和校验后替换目标；落盘后再次比较内容并记录 SHA256。文件操作在后台执行。
- 自动生成读取信息与哈希说明文件。说明文件失败时明确提示，已保存并校验的原始文件仍可使用。`NFC_EXPORT` 记录大小、哈希和结果，不记录实际 UID 或路径。
- 沿用 v3.2.12 的读取参数、最多两次恢复、取消与清理流程，不改 BLE 输入策略或 133Hz 请求。

本机 v3.2.12 已用 Pro2 固件 1.1.5 完成一次实卡读取与完整性校验，读卡期间 FD2 为 133.03Hz。本版的读卡协议不变；跨标签、跨电脑连续成功率和模拟器导入仍需积累实测。

范围：无线只读和文件保存。USB NFC、写卡、2KB 完整读取、游戏自动 NFC 透传及加密真实性认证尚未接入。

验证：932294 项离线断言通过，包含 540 / 572 字节逐字节导出、哈希说明、覆盖保护、缺少签名、坏数据拒绝、说明文件失败与临时文件清理；NFC 页面检查通过。实机连续读卡、移卡后恢复和模拟器导入仍建议继续验证，不阻塞本版读卡功能使用。
