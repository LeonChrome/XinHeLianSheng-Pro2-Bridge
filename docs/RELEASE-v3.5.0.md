# v3.5.0 · 统一蓝牙转发与 NFC

这是本轮收尾版本。本机连接和跨设备外发统一到首页，原有四模式游玩、改键与诊断继续保留。

## 更新

- 首页共用四种实体输入，选择本机游玩或蓝牙转发；不再另开转发窗口。
- 蓝牙外发增加 Xbox One S、PS5 / DualSense，与 Pro1 使用各自的描述符、输入和反馈格式。
- 手动选择发射适配器；准备前备份、停止后恢复。保留启动就绪握手和选中设备错误恢复保护。
- 外发沿用键位映射、背键 / C 键、触控手势及震动强度；补充连发取消、输入间隙及定时震动处理。
- 集成 Pro2 BLE / USB 的只读 NFC；校验通过后导出 540 字节文件。Pro1 外发可载入只读快照并响应 NFC 请求。
- 上传对应源码、构建说明、许可与源码依赖包。

## 使用

退出旧助手，运行 EXE。本机输出首次按提示安装 USBIP；外发选择身份和适配器，再让接收设备配对。名称分别为 `Pro Controller`、`Xbox Wireless Controller`、`Wireless Controller`。更换身份或重开外发后，接收端可能需要忘记旧条目再配对。

USB 输入只需一只发射适配器，无线输入需要另一只系统蓝牙。当前发射后端仅覆盖 Realtek `0BDA:0852`、Actions `10D7:B012`；不会自动接管其他型号或在拔出后改选别的设备。停止或退出时恢复由本工具临时切换的驱动；恢复脚本保存在 `%LOCALAPPDATA%\PRO2WirelessReceiverControlBoard\radio\时间戳\`。

## 验证与限制

本次通过原生协议自检、C# 协议 / NFC 回放、19 组跨语言数据包、localhost 启动握手、原有输入 / 输出回归、驱动恢复模拟和最终 EXE 启动检查。测试不等于新身份已在全部接收端验收。

Pro1 外发已有实体按键 / 摇杆响应记录；Xbox / PS5 外发仍待不同接收端实测。PS5 蓝牙原生触觉音频、自适应扳机、PS5 / Xbox 主机认证未实现。外发 66.7 / 133 / 250Hz 是请求上限，不是接收设备实测速率。原生 Pro2 蓝牙身份暂未模拟。

NFC 长度、UID/BCC 与格式检查不等于真实性认证；Pro1 外发的接收端游戏 amiibo 流程仍待验收。主程序本机游玩最多四槽位；当前跨设备外发为一只手柄，不承诺四路同时外发。
