# v3.5.2 · Switch 转发连接修复（本地待验收）

修正蓝牙 HID 关闭通知丢失会话编号的问题，避免通道已关闭时仍显示已连接、重复向旧会话请求发送。

- Pro1 外发允许接收端协商 Sniff 模式，仍保留有限的主动模式请求。
- Pro1 外发连接意外关闭后，保留实体输入。等待旧 ACL 释放，再向原接收端重连；最多两次，单轮等待上限 20 秒。不切换模式、不重置适配器、不清除配对。接收端发出解除绑定命令时不自动重连。
- 恢复时界面显示“接收端连接中断 · 正在恢复 HID 连接”；恢复握手重新初始化报告模式，丢弃旧输出与按键队列。
- 增加 HID 生命周期、L2CAP 关闭方向、USB/HCI 发送状态和恢复结果日志。不记录配对密钥、标签内容。

本机 2026-11-17 07:34 的追踪记录：实体 Pro2 USB 输入约 250Hz；停发时 USB 不忙，HCI 有 6 个空闲缓冲，但 HID 会话已不存在。约 3 秒后收到接收端 ACL 断开（0x13）。这排除了该次故障由 USB 发送忙或 HCI 缓冲占满造成；尚不能从旧日志断定接收端首先关闭 HID 的原因。

离线回归包含实际 BTstack 关闭事件的复现、两种通道关闭顺序、有限重连预算及前端恢复状态。本版需继续接受 Switch 实机验证，暂不上传 GitHub，不宣称持续稳定或接收端 133Hz 已通过。
