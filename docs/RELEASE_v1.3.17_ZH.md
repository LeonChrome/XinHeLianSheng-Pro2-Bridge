# v1.3.17 · 首页蓝牙优化

- Win10 首页新增“优化蓝牙 · Win10”，不再藏在高级设置中；Win11 不显示此入口。
- 默认固定 7.5ms，保留三组预设、“授权并测试”和“恢复原参数”。仅展开不会修改系统。
- 提示精简为授权要求、可能的蓝牙断开、真实输入验收及恢复方法。
- 默认窗口优化折叠 / 展开布局，操作忙碌时禁用参数按钮。
- 保留四种游戏模式、背键 / C 键、电量更新及真实输入诊断。

退出旧版后再打开新版。Win10 参数优化会修改系统全局 BLE 默认值，自动备份、写后校验并提供恢复；可能需要重启 Windows。实际提速由真实 FD2 / Parsed 决定，不保证全部硬件达到 133Hz。

本地离线回归通过 54,416 项，最终 EXE 预览启动检查通过；此结果不是新增硬件的 133Hz 实机验收。
