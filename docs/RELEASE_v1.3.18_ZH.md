# v1.3.18 · 蓝牙预设诊断

- “系统与蓝牙信息”新增逐组预设结果，直接“复制全部信息”即可反馈，无需再翻日志找标签。
- Win11 显示固定 7.5ms、7.5–15ms、系统吞吐量优先、固定 15ms：是否调用 API、请求参数、Status / HRESULT、真实 FD2 / Parsed、实际间隔、最终复核及恢复记录。
- Win10 显示三组参数目录、最近配置 / 恢复操作，以及本次程序的提权、退出码和重启核实结果。参数目录不是执行结果，不会自动修改系统。
- 修正 10 秒测量窗口的计时边界；原连接测量无效时最多在同一连接补测一次，未进入预设测试会明确提示。
- 修正请求拒绝、清理失败与流程完成提示；断开 / 取消前的诊断独立保存，不会覆盖新连接的结果。
- 读取已保存的上一轮结果并标为历史；旧版未采集的 API 状态显示“未记录”，不反推。查看、复制和保存不会触发新测试或电量查询。

退出旧版后再打开新版。已有 v1.3.17 的完整保存记录可只读查看；没有保存的请求返回码无法事后补齐。保留四种游戏模式、背键 / C 键、电量更新及 Win10 首页授权 / 恢复入口。

Win10 优化仍需明确授权，会修改全局 BLE 默认值，带备份、写后校验和恢复，可能需要重启 Windows。Win11 不套用 Win10 全局配置。

真实输入达到 60Hz 可兼容游玩；目标为 133Hz，但请求成功不等于实际提速，不保证全部硬件达到目标。本版通过 54,745 项离线检查、0 警告构建及最终 EXE 预览启动检查；不等于对方 Intel 电脑的 133Hz 实机验收。
