# v1.3.22 · 推荐下载

用电脑蓝牙无线连接 Switch 2 Pro 手柄，在 Steam 和其他 PC 游戏中使用。

## 功能

- Steam / Pro2、Pro1、Xbox、PS5 四种兼容模式。
- Pro1 / Xbox / PS5 支持背键和 C 键映射：单键、组合键、连发、顺序动作、延迟。
- 震动强度、PS5 触觉转换、陀螺仪校准。
- 真实输入频率、电量档位、固件和耳机状态；自动重连、首页蓝牙诊断、优化与恢复工具。

## 本次更新

- 修复最小化到托盘再恢复后，首页输入频率停止刷新的问题。
- 电量改为每 10 分钟更新；保留速率与连接安全检查，异常时暂停，轻微间隙超限最多在恢复稳定后重试一次。
- PS5 默认音频保护内置，不再需要设置开关；不禁用触觉音频端点。
- 长时间运行达到详细日志上限后，近期速率与异常仍继续记录。
- 包含此前的蓝牙手动重启与连接诊断改进。

## 下载与使用

下载 **PRO2ControllerAssistant-v1.3.22-win-x64.exe** 即可。先退出旧版，让手柄使用 PRO2 模式并开启配对广播，再点击“连接 Pro2”。无需先在 Windows 设置中配对。

支持 Windows 10 2004 及以上 / Windows 11 x64，需 BLE 蓝牙。首次使用按提示安装内置 USBIP 驱动，可能需要管理员授权或重启；无需另装 .NET、VIIPER。

目标为真实 133Hz，达到 60Hz 可兼容游玩。Win10 优化需授权，会修改全局 BLE 参数，提供备份和恢复，可能需要重启。实际速率取决于系统、蓝牙与驱动，不保证所有电脑达到 133Hz。无线耳机音频及跨设备蓝牙转发不属于本版功能。

2026-10-14，本机连续约 2 小时 10 分钟：真实 FD2 平均 132.63Hz，无断联、重连或虚拟设备重建；13 次定时电量更新成功。电量查询附近存在约 30～38ms 的短间隙，没有持续降速。这不代表所有电脑或全部游戏都已验证。
