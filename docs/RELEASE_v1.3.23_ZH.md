# v1.3.23 · PS5 震动修复 · 推荐下载

让 Switch 2 Pro 手柄无线连接 Windows，支持 Steam / Pro2、Pro1、Xbox、PS5 兼容模式。

## 本次修复

- 补齐 PS5 模式的一条普通震动接收路径：游戏通过 USB HID 控制请求发送的震动，之前可能回复成功却没有送入转换器。
- 两种 USB 输出方式现在统一转发，检查震动开始、更新和停止，避免漏接或重复发送。
- 保留原生触觉音频转换，增加反馈路径日志，便于继续排查游戏兼容性。
- 蓝牙连接、真实输入速率、电量更新、背键 / C 键和界面沿用原有逻辑。

## 下载与使用

下载 **PRO2ControllerAssistant-v1.3.23-win-x64.exe**。先从托盘退出旧版，再打开新版；手柄保持 PRO2 模式并开启配对广播，在助手中选择需要的游戏模式。

支持 Windows 10 2004 及以上 / Windows 11 x64，需 BLE 蓝牙。EXE 内置 .NET、VIIPER 和 USBIP 安装器；首次使用按提示安装驱动，可能需要管理员授权或重启。已安装 USBIP 的电脑不需要为本次更新重新安装。

## 验证与范围

- 修复前后的离线对照、DualSense / Pro1 后端回归、55,048 项核心离线检查及最终 EXE 启动检查通过。
- 已核对 EXE 内置的是本次修复后的后端，而非旧缓存版本。
- 尚未完成《终末地》的实机震动验收，不将本次修复表述为该游戏已全面兼容。游戏仍需向虚拟 DualSense 提供可用反馈。
- 133Hz 是真实输入目标，不保证所有电脑达到；实际速率以首页实测为准。Win10 蓝牙优化仍需授权，提供备份和恢复。

旧版保留，可按需回退。
