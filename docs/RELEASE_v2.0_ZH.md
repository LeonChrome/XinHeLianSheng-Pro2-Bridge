# PRO2 手柄助手 v2.0

[下载 Windows x64 EXE](https://github.com/LeonChrome/XinHeLianSheng-Pro2-Bridge/releases/download/pro2-v2.0/PRO2ControllerAssistant-v2.0-win-x64.exe)

让 Nintendo Switch 2 Pro 手柄无线连接 Windows，在 Steam 中使用，或切换为 Pro1、Xbox、PS5 兼容模式。无需专用接收器。

## 本次更新

- 修复 USB 输入重复、短按覆盖；电脑卡顿后不再补播过期按键。
- 校正运动时间戳，区分真实输入与协议重采样；无效体感不再制造姿态跳变。
- 修正 Pro1 摇杆校准范围，移除输出端额外的中心吸附，保留手柄校准。
- 完善普通震动的持续、停止、切换及失败保护；刷新与源命令分别计数。
- 内置后端同步更新；原有四模式、背键 / C 键、蓝牙优化、电量更新和默认音频保护继续保留。

## 使用

从托盘退出旧版，打开新 EXE，让 Pro2 保持 PRO2 模式并开启配对广播，再点击“连接 Pro2”。无需先在 Windows 蓝牙设置中添加手柄。

支持 Windows 10 2004 及以上 / Windows 11 x64，需可用的 BLE 蓝牙。EXE 自带 .NET 和后端；首次使用仍需按提示安装内置 USBIP 驱动，可能需要管理员授权或重启。旧设置继续沿用。

目标是真实133Hz，达到60Hz也允许游玩；实际速率以首页FD2为准，不保证所有蓝牙硬件达到133Hz。低速时查看首页诊断；Win10可在首页授权优化，修改前备份并支持恢复。

## 验证与边界

- 768,314项离线检查、7个后端测试包及最终EXE启动检查通过。
- 合成源经真实localhost USBIP服务：严格模式133Hz三组均60源→60报告；PS5的250Hz组113源→113报告，原6ms调度瓶颈已修复。
- 队列时龄、并发、短按、停止、时钟回绕和跨模式转换均有回归；这些不代替实体三轴动作、长震动或具体游戏验收，本轮未新增Win11实机验收。
- Pro2的4ms协议重采样与真实FD2分开计数，不是新增250Hz物理采样。过载仍可能合并或丢弃，会记录计数。
- Xbox模式没有原生体感；PS5摇杆、加速度量程及触觉转换存在协议限制，不承诺物理无损。无线耳机音频和跨设备转发尚不支持。
