## 连接与重连

自动连接发现上次手柄地址或明确 Pro2 身份的广播后，可提前结束扫描。Windows 断线事件直接唤醒重连守护，减少等待下一次轮询的时间。首次连接身份不明时继续完整扫描；手动列表仍收集完整候选。

初始化、电量读取、真实 FD2 验收、2 秒输入中断保护和连续失败退避继续保留。日志新增发现、BLE 就绪、游戏输出就绪和断线后恢复耗时，实际速度以本机记录为准，不承诺所有设备秒连。

## 游戏按键图标

在“设置 → 游戏按键图标 → 管理游戏图标”中使用。当前适配《影之刃零》Steam 版：保持 PS5 模式，按实际位置显示 Pro2 键名——**上 X、右 A、下 B、左 Y**，并覆盖肩键、扳机、摇杆按下、加减号和截图提示。

自动发现多 Steam 库，支持不同盘符、中文和空格路径，也可手动选择目录。安装前检查游戏版本和文件；游戏运行时不修改，目录需要权限时请求管理员授权。只添加独立补丁，不覆盖原游戏 EXE、主资源包或存档。已知旧补丁可更新，游戏更新后仍可还原；同名文件被外部修改时停止操作。

触摸板方向手势、整张手柄示意图保留。图标不会跟随背键 / C 键自定义实时变化，也不是所有 Steam 游戏的通用图标替换。

## PS5 与原有功能

合入此前 PS5 原生 USB 识别修复。《影之刃零》已实测关闭 Steam Input 可操作并收到触觉输入；其他游戏仍取决于其原生 DualSense 支持。PS5 触觉经过转换，不承诺物理无损。

保留 Pro2 / Pro1 / Xbox / PS5 四模式、背键 / C 键、电量更新、陀螺仪、震动强度、蓝牙诊断和默认音频保护。虚拟设备后端沿用已验证的 v2.1.1。

## 使用与兼容

从托盘退出旧版，打开新 EXE，保持 Pro2 开机并开启配对广播，再点击连接。旧设置继续沿用，无需先在 Windows 蓝牙设置里添加手柄。

支持 Windows 10 2004 及以上 / Windows 11 x64。EXE 内置 .NET 和后端；首次仍需按提示安装 USBIP 驱动，可能需要管理员授权或重启。目标是真实 133Hz，达到 60Hz 允许游玩；不同系统、适配器和驱动不保证同样速率。Win10 可在首页授权优化，修改前备份并支持恢复。

文件事务、路径发现、图标引用、连接策略和界面有离线检查；这些不代替另一台电脑或真实手柄的长时验收。无线耳机音频及跨设备蓝牙转发尚不支持。
