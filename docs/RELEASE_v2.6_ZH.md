# PRO2 手柄助手 v2.6

- PS5 模式的左背键、右背键和 C 键新增触控板动作：中央轻触、上／下／左／右滑动、顺时针／逆时针画圈。保留触摸板点击，可与普通按键组合。
- 支持手势时长、延迟、按住连发和顺序动作。默认不重复；停止动作、断联和切换映射时释放触点。多个键同时请求手势时，只执行一个触点，冲突动作不排队。
- 《影之刃零》图标补丁升级到 0.3：补充菜单动作表、文本内嵌图标、物品与装备选中提示及 PS4 回退数据。按物理位置替换：△→X、○→A、×→B、□→Y。
- 保留多 Steam 库检测、手选路径、旧补丁升级前备份与恢复。仅支持已核对的游戏版本；游戏更新后重新检测。

## 使用

触控板：打开“背键／C 键”，选择 PS5 和要修改的键，启用映射，选择“触控板动作”，设置时长，再保存并应用。想按一次完成手势，选“单次按键”；选“按住映射”时，松开会停止。只有支持 DualSense 触控坐标的游戏或工具会识别滑动与画圈，Steam Input 的配置也会影响游戏收到的输入。

图标：退出游戏，在“设置 → 游戏按键图标 → 管理游戏图标”中检测目录，点击“更新 Pro2 图标”。更新助手本身不会自动改游戏文件；需要恢复时点击“恢复原图标”。

## 验证范围

已检查轨迹方向、触点释放、模式隔离、旧配置迁移、顺序与连发、UI 绑定和布局，并用 C# 实际输出包验证后端生成的 USB HID 触点坐标。图标补丁的 18 个资源完成打包回读和引用校验；实机游戏画面与具体游戏的触控手势识别仍需试玩确认，不宣称所有界面已 100% 替换。

v2.5 的自动休眠与 Win10 连接引导继续保留。自动休眠可能占用手柄配对记录；若 NS2 主机连接记录被挤掉，重新与主机配对即可。
