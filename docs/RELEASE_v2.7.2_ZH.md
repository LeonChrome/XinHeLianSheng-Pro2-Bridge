# v2.7.2：每只手柄单独选择模式

首页“多手柄”提供四个槽位，每只可分别选择 **Steam / Pro2、Pro1、Xbox 或 PS5**。例如四只同时用 Xbox，或 Pro2 + Pro1 + Xbox + PS5 混用。

- 模式可离线选择并保存，连接后按各自配置创建输出；旧配置按原先共用模式迁移。
- 改选后点击本槽位“应用模式”。只替换该槽位的虚拟设备，不重连实体 BLE，不重建其他三个槽位。正在使用该槽位的游戏可能需要重新选择控制器。
- 创建新模式失败时尝试恢复本槽位原模式；恢复失败会明确显示输出未启动，不标成切换成功。
- 首页模式仅控制手柄 1；各槽位显示实际输出及待应用的模式，诊断中分别记录身份和切换结果。
- 每只保持独立输入、反馈、重连和休眠状态。同一模式共用该模式的背键设置，按住、连发及触点运行状态在每只会话中分别维护。
- PS5 音频保护按所有实际虚拟输出检查；手柄 1 使用其他模式时，不停止其他 PS5 槽位所需的保护。

保留 [v2.7.1 的休眠保护与连接诊断](RELEASE_v2.7.1_ZH.md)。自动休眠首次登记唤醒可能挤掉 NS2 主机配对记录；如发生，重新与主机配对即可。

验证覆盖四种模式分别四路输入、四组混合模式的协议与反馈隔离、256 种模式组合、单槽位切换和失败恢复、配置迁移以及界面绑定。**这些是离线与回环验证，不是四只实体 Pro2 的蓝牙空口或 Windows 游戏识别长测。** 实际同时连接数量和每只速率受系统、适配器及驱动影响，不能保证任意电脑都同时达到四路 133Hz。
