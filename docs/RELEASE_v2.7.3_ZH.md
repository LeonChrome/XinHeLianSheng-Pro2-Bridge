# v2.7.3：四槽位独立模式与设备身份

首页“多手柄”提供四个槽位，各自选择 **Steam / Pro2、Pro1、Xbox 或 PS5**。可以四只同模式，也可以四种模式混用。

- 模式可离线选择并保存，旧配置按原先共用模式迁移。先让第一只进入游戏，再逐只连接其他槽位。
- 改选后点本槽位“应用模式”。只替换这一只的虚拟输出，保留实体 BLE、其他槽位和休眠状态；创建失败时尝试恢复原模式。
- 首页模式仅控制手柄 1。各槽位分别显示实际输出与待应用模式；切换后游戏可能需要重新选择控制器。
- 修复 Xbox 后端忽略传入序列号的问题，四槽位使用各自的 USB 身份；加固震动回调更换的并发访问。
- 每只独立输入、反馈、重连和休眠。同模式共用该模式的背键配置，按住、连发和触点运行状态在各会话中独立维护。
- PS5 音频保护按全部实际输出检查；主手柄选其他模式时，其他 PS5 槽位仍保留保护。
- 保留首页连接失败提示、系统与蓝牙信息、逐组参数测试、低速优化和休眠保护。原因未确认时明确说明，不仅凭驱动日期或蓝牙版本下结论。

**验证范围**：四种模式分别四路输入、四组混合模式的输入与反馈隔离、256 种模式配置组合、单槽位切换与恢复、配置迁移及界面检查。Go 后端另验证四模式的四实例身份，以及 Xbox 普通震动、PS5 HID 与触觉 PCM 回调隔离。

以上不等于四只实体手柄的蓝牙空口、Windows 游戏识别或长期稳定性测试。**四只实体 Pro2 的并发长测仍待完成**，不保证任意电脑四路同时达到 133Hz。

自动休眠首次登记唤醒可能挤掉 NS2 主机配对记录；如发生，重新与主机配对即可。无法确认蓝牙接口归属时暂缓休眠，保留连接。
