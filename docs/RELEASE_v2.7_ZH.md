# PRO2 手柄助手 v2.7 · 多手柄与蓝牙兼容改进

## 本次修复

- 首页增加“多手柄”入口，可以逐只连接、暂停、移除第二至第四只手柄。所有手柄使用首页选择的同一种输出模式。
- 运行中新增手柄只创建对应虚拟设备，不重建第一只或其他已有设备。各自显示真实 FD2、解析速率、Notify 间隙和优化结果。
- 地址排除在获取连接锁后重新计算，防止并发排队时重复连接同一只；启用但离线的手柄保留槽位地址，避免重连时相互抢占。
- 保存已启用的槽位；重启后不再只保留第一只。移除多余槽位不会清理其他手柄。
- PS5 新增槽位具有独立、稳定的协议地址；保留第一只的旧身份，避免只靠 USB 序列号区分手柄。
- Pro2 后端对并发创建／释放时的序列号注册增加锁保护。

## 蓝牙适配

- Win11 的每个连接分别自动测量、尝试已有的 7.5ms、7.5～15ms、系统吞吐量预设和 15ms 路线；接受请求不等于达标，以真实 FD2 / Parsed 为准。
- 参数优化通过同一个 BLE 操作锁串行执行。若其他手柄的缓存输入明显下降或中断，停止继续试验，恢复试验前的请求并复测；不能确认恢复时明确记录。
- 优化缓存增加实体手柄和同时连接数量，避免把单手柄结果直接沿用到多手柄条件。
- Win10 保留首页管理员授权、备份、实测与恢复；这些是系统全局参数，不静默为某只手柄改写或自动重启其他设备。
- “系统与蓝牙信息”补充各槽位缓存诊断和预设记录。系统默认适配器仍不等于已确认的每条链路归属。

## 使用

先连接第一只并进入游戏，再打开首页“多手柄”，逐只开启配对并点击对应“连接”。暂停保留虚拟设备；移除会停掉对应额外槽位。不要同时打开另一份助手占用实体手柄。

## 已验证与未验证

自动回归覆盖四种模式下四个并发 C# 输入消费者、独立回环数据流、Xbox 震动回传隔离、一只输入断开后的其余通道、地址争用、参数回退、配置保存与界面绑定；后端各模式和 USB 协议回归通过。

本机为 Windows 10 Build 19045、Realtek 0BDA:0852，驱动 18.4032.2510.900。已自动尝试真实 BLE 连接，本轮服务发现返回 Unreachable，没有得到 FD2 数据。因此尚未验证两只实体手柄同时连接、实际长时间无线稳定性，也没有本轮 Win11 实机结果；不保证所有系统和蓝牙设备同时达到 133Hz。

自动休眠、触控板手势、背键 / C 键、图标补丁等功能继续保留。启用自动休眠可能占用 NS2 主机配对记录，重新与主机配对即可恢复主机使用。
