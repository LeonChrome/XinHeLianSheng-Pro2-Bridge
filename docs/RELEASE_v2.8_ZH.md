# v2.8：键位映射与虚拟手柄连接修复

## 新增

- **键位映射页**：四种输出模式分别保存 ABXY 设置；支持位置、字母对应预设与自定义，未连接手柄也能设置。
- **手柄图片**：首页与映射页换用用户提供图片的透明背景版本，辅助识别实体按键位置。
- **虚拟输出状态**：区分实体 BLE 已连接、USBIP 已挂载和 Windows 输入接口已就绪；异常在首页与多手柄窗口显示。
- **系统设备事件**：“系统与蓝牙信息”加入最近相关系统警告、错误及每个虚拟手柄的状态。仅只读采集，不读取安全审计日志。

## 修复

- 旧 API 数据流退出时，不再为新数据流仍在使用的虚拟手柄启动删除倒计时；旧设备的延迟清理也不能删除复用了编号的新设备。
- 同一个虚拟手柄只允许一个 USBIP 导入连接；不同手柄分别管理。
- 运行中持续确认挂载丢失或设备启动失败时，仅恢复对应手柄，每次会话最多自动尝试两次。查询失败、设备归属不明确时不自动卸载。
- 重新挂载前必须确认旧挂载消失，避免反复 attach 积累端口。
- 端口存在不再直接等于手柄就绪，需结合 Windows HID / XInput 接口状态。

## 键位怎样对应

实体 Pro2 的按键位置固定为：**上 X、右 A、下 B、左 Y**。

| 实体按键 | 默认按位置 → Xbox | 默认按位置 → PS5 | Pro2 字母对应 → Xbox | Pro2 字母对应 → PS5 |
|---|---|---|---|---|
| X（上） | Y（上） | △（上） | X（左） | □（左） |
| A（右） | B（右） | ○（右） | A（下） | ×（下） |
| B（下） | A（下） | ×（下） | B（右） | ○（右） |
| Y（左） | X（左） | □（左） | Y（上） | △（上） |

Xbox 与 PS5 的位置预设相同，只是键名不同；Pro1 / Pro2 模式的默认位置和原本的 Nintendo 字母本就一致。

本页只改 ABXY。背键 / C 键按输出手柄的键名设置，不再经过 ABXY 二次转换。同种输出模式的多个槽位共用该模式配置。

按住 ABXY 时修改设置，需松开后再按。最终顺序为：**实体按键 → 本页映射 → 背键 / C 键输出 → Steam Input / 游戏映射**。游戏内自行改键会继续叠加；本页不会自动替换游戏按键图标。

## 使用与验证范围

先从托盘退出旧助手，再打开新版。保留现有 Win10 / Win11 BLE 路线、休眠、震动、体感与 USBIP 内置安装器；不自动更新驱动或重启蓝牙。

已通过 Go 后端测试、920,554 项离线断言、界面渲染与本机只读 PnP 检查。并发导入、旧流延迟退出和四路隔离使用本地模拟连接复现；尚未在反馈故障的电脑上实测，不承诺消除所有驱动或硬件问题。只有安全审计事件的 Windows 日志不能确定 Pro2 连接失败原因。
