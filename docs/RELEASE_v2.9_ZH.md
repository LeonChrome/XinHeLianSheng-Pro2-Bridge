# v2.9 · 启动兼容、USBIP 定位与映射改进

适用于 Windows 10 2004 及以上 / Windows 11 x64。配置沿用旧版，先从托盘退出旧助手再打开。

## 本次更新

- **启动**：独立启动器准备并校验内置运行文件，默认使用软件绘制。发现早期原生异常时只尝试一次兼容启动，保留退出码与启动记录；兼容回退暂停托盘、启动时自动连接与检测，可手动连接。另提供完整 ZIP 文件夹版。
- **USBIP**：修正大量输出堵住管道时的假超时；增加程序所在目录、安装记录补充项、已运行客户端等查找来源。找不到时弹出选择窗口；绑定前验证 `usbip.exe`，驱动状态另行检查。设置中可更改或恢复自动查找，诊断里显示路径与状态。
- **摇杆**：在“键位映射 → 摇杆中心死区”独立设置左右摇杆 0–20%，四种模式共用，默认 4%。减小软件死区后，持续的小幅输入不再被自动归零；不改动原始 FD2、电量、陀螺仪和已保存的物理校准。游戏自身死区仍需另调。
- **背键 / C 键**：按方位选择面部按键和方向键，组合键、动作顺序、连发节奏可预览；时间参数按需展开，新增连发节奏预设。编辑仍需保存，按住连发松开停止，不改原有动作引擎。
- **蓝牙发现**：补充 Pro 2 / NS2Pro 名称及 UUID 线索识别；无名称、无匹配标识的广播也保留有限样本供手动模式核对。未确认 Pro2 接口前不发送初始化命令，不把“没找到手柄”误判为 USBIP 故障。
- **游戏图标**：取消整份 EXE / 容器哈希变化就拒绝的限制，按补丁目标资源标识与容器格式检查。保留原包、备份、冲突检测和一键还原；游戏若改变资源结构，仍可能需要适配，标识匹配也不等于已确认游戏中每一处显示。
- **离线后重连**：包含 v2.8.1 的唤醒广播接续与 GATT 超时释放改进，防止卡住的旧请求和新请求重叠。

## 已做检查

- 92 万余项离线断言：四模式数据、四槽位隔离、按键安全、震动与体感协议、休眠重连、死区边界、图标安装 / 升级 / 恢复、USBIP 查找和界面布局。
- EXE 首次准备、再次启动、缓存损坏后重建、兼容模式启动；启动器模拟原生错误退出后可转入兼容分支。
- 非默认目录（含中文、空格、逗号）的实际 USBIP 客户端命令检查。
- 本机更新后的《影之刃零》目标资源检查通过，18/18；未进游戏逐页验收。

这些检查没有重启蓝牙、更换驱动或改写现有 BLE 系统参数，也不代表已在反馈故障的电脑复现与解决。`0xc0000005` 截图尚不能确定故障模块；新版本提供兼容处理和可读记录，不保证所有系统都能避开原生异常。蓝牙低速须看真实 FD2 和连接证据，不能仅凭虚拟 USB 状态归因。

## 使用与恢复

首次打开 EXE 请等几秒准备文件；无需额外安装 .NET。备用 ZIP 完整解压后运行 `PRO2ControllerAssistant.exe`。USBIP 内核驱动仍按首次使用提示安装。

- USBIP 绑定：设置中重新选择 `usbip.exe`，或“恢复自动查找”。
- 死区：恢复 4% 后点击“保存死区”。
- 图标：退出游戏，到“管理游戏图标”点“恢复原图标”。
- Win10 蓝牙参数：沿用首页高级面板中的备份恢复入口，本次升级不会自行更改参数。

自动休眠可能挤掉手柄里的 NS2 主机记录；发生后重新与主机配对即可。真实 133Hz、四只实体手柄的并发与长时间稳定性仍需对应硬件实测。
