# v3.0.1 · USB 连接修复预览

修复 v3.0 有线接入失败：

- 同时识别 Windows 的 `DeviceInterfaceGUID` 和 `DeviceInterfaceGUIDs`，不再漏掉已安装的 Pro2 WinUSB 接口。
- USB 接口被拒绝访问时提示先正常退出 Steam／其他手柄工具；日志记录失败阶段和 Windows 错误码，避免误报缺少驱动。
- 移除游戏输入不需要、部分固件不应答的 NFC 旁路初始化，保留必要 USB 输入与震动配置。

**本机真实 Pro2 USB 实测约 30 秒：249.99Hz，间隔 P50 4.00ms、P95 4.02ms，解析失败 0。** 这是实体输入测试，不是虚拟补帧；尚不代表所有电脑或长时间游戏都已验收。

使用顺序：正常退出 Steam → 打开助手 → 首页“输入 / NFC”接入 Pro2 USB → 选择输出模式 → 再启动 Steam。

本次没有安装或替换驱动、没有修改设备权限、配对或固件。Pro1 和实卡 NFC 仍待硬件验收，Pro2 NFC 尚未接入。v2.9 继续保留为稳定版。
