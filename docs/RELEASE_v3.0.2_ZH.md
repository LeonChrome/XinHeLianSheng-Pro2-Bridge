# v3.0.2 · 校准与连接修复预览

- 有线 Pro2、Pro1 USB／蓝牙接入摇杆零位、行程和陀螺仪校准，修复按钮仍调用 BLE 通路的问题。
- 设置的“校准与连接”可选择手柄，显示采样倒计时、成功或失败原因；只处理所选槽位。
- 实体 HID 的摇杆校准按设备标识保存，重新连接后加载。中断、采样不完整或保存失败时保留旧配置；不写手柄固件。
- 去掉实体 HID 陀螺仪的重复零偏处理；三秒静置校准等待真实结果后再提示完成。
- 断开后保留原输入方式，首页和多手柄窗口可重新连接，不会误转去扫描 BLE；已在线的实体输入重复点击接入时不重新初始化。
- 虚拟输出未就绪时显示输出问题，不再仅凭有线输入在线提示全部正常。

使用：从托盘退出旧助手再打开新版。有线 Pro2 先正常退出 Steam，接入助手后再启动 Steam。设置中选择需要校准的手柄，先零位、再行程；陀螺仪校准时静置平面。

此版修复通过协议回放及界面回归。尚不能代替 Pro1 实机、各模式长时间游戏和用户操作校准的验收。未安装或更换任何驱动；原 Pro2 BLE 路线保留。
