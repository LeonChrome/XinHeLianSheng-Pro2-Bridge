# v3.0 · 多输入预览

在原有程序中增加 Pro1 蓝牙／USB、Pro2 USB 输入，复用四种输出和四槽位。

- 首页新增“输入 / NFC”：选实体设备、槽位，再选择游戏输出模式。
- Pro1 使用 Windows 传统蓝牙 HID，需先在系统配对；Pro2 BLE 使用方法不变。
- 拔插后按同一设备身份重连，虚拟手柄保持在线；防止输入读回自己的虚拟设备。
- 频率按有效实体报告计数，初始化与 NFC 应答不计入；USB 不使用 BLE 的 7.5ms 优化。
- Pro1 蓝牙新增 NFC 只读实验，可保存完整 NTAG215 原始文件；读取时暂停本槽位输入和震动，结束后恢复。

Pro2 USB 目标 250Hz，Pro1 按原生速率转发。新输入与 NFC 已通过离线回放，尚待实机验收；Pro2 NFC 尚不支持。v2.9 继续作为已发布的稳定版本保留。

Windows 10 2004 及以上 / Windows 11 x64。EXE 自带 .NET 和 VIIPER；虚拟输出仍需 USBIP 驱动。Pro2 USB 只使用已有的厂商接口 WinUSB 绑定，缺失时提示，不自动换驱动。
