# v3.1.1 · 无线自动高速连接

- 默认开启“连接时优先 133Hz”，一次性修正旧设置遗留的关闭状态；升级后若主动关闭，会保留用户选择。
- Win11 在同一系统、蓝牙驱动、手柄及并发环境已有固定 7.5ms 高速成功记录时，连接阶段优先恢复该方案。仍需两个当前完整输入窗口确认，不凭缓存或 API 返回值显示 133Hz。
- 缓存方案未通过就恢复原请求，转入原有自动预设比较；不反复断连、不伪造回报率。其他手柄的真实输入也纳入保护。
- Win10 保留已授权的系统配置流程，不静默提权或修改全局蓝牙设置。

退出旧助手后运行新版，Pro2 无线连接会自动完成协商和测速。无法保证最初一个通知就达到 133Hz；已验证缓存方案仍需要约 20 秒测速，首次或环境变化可能更久。完成后按实际频率进入游戏，未达标则继续给出诊断与兼容游玩状态。

本机此前日志已确认手动固定 7.5ms 将约 66Hz 提升到约 132Hz。新版自动流程通过离线状态机回归及 EXE 启动检查；本轮未中断正在使用的连接，新的连接流程仍需下一次真实连接验收。
