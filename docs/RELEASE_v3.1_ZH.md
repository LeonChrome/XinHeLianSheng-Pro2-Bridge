# v3.1 · 统一连接与多手柄预览

- 首页和“管理手柄”统一选择 Pro2 无线／有线、Pro1 无线／有线，四个槽位各自选择实体手柄与游戏输出模式。
- 连接方式和实体设备按槽位记住；改选后点“连接”才切换，避免改选时意外断线。不会把失踪的设备静默换成另一只手柄。
- 第二至第四槽位可先连接 Pro2 无线，真实输入达到游玩门槛后创建自己的输出；不再强制等待手柄 1。
- 接入实体手柄时不重复初始化已在线的同一设备；断开后可以按原方式重新连接。单个槽位失败不阻断其他槽位。
- 包含 v3.0.2 的摇杆与陀螺仪校准修复，各槽位显示独立结果。
- NFC 窗口只负责读卡，连接操作回归同一入口；读卡期间保护该槽位，禁止更换连接和输出模式。
- 自动休眠与 BLE 参数优化仅用于 Pro2 无线。虚拟输出启动失败不会反复自动弹出安装向导，失败原因留在对应槽位。

使用：退出旧助手后打开新版。首页选择手柄 1 的连接方式；多只手柄进入“管理手柄”。有线用 USB 数据线，Pro1 无线先完成 Windows 蓝牙配对；Pro2 无线仍直接由助手扫描连接。每只的“游戏输出”再选 Steam / Pro2、Pro1、Xbox 或 PS5。

Pro2 USB 请先退出 Steam，接入助手后再启动 Steam，避免接口占用。USBIP 仍是虚拟输出所需驱动；本次开发和离线检查没有安装或更换驱动。

此版为多输入预览，稳定推荐仍保留 v2.9。回归测试覆盖四槽位配置、输入切换隔离、混合 HID 输入、四种虚拟输出、校准、NFC 恢复和界面绑定；**不等于四只实体手柄或所有网卡已完成实机长测**。Pro1 实机、NFC 实卡和各模式长时间游戏仍需继续验收。
