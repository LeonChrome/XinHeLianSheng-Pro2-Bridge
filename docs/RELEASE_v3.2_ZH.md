# v3.2 · 连接界面更新

- 首页直接展示 Pro2 无线、Pro2 USB、Pro1 无线、Pro1 USB 四张图卡，内置高清产品图片。绿框与勾选表示当前选择；点击连接后才应用。
- 多手柄窗口使用相同图卡，每只手柄独立选择输入和游戏输出。有线、无线可混用。
- 加入短暂的悬停抬升和选中淡入动画。窗口隐藏、禁用或最小化时停止动画；尊重 Windows 的动画设置，无持续播放的后台动画。
- 首页出现低速诊断时自动收紧图卡，保留提示和操作按钮空间。保留 Pro1 蓝牙的 Windows 配对入口、实体手柄选择及刷新。
- 延续 v3.1.1 的无线自动高速协商、真实输入测速和已验证方案缓存。

退出旧助手后运行新版。图片和运行库均已内置，无需下载图片或单独安装 .NET；虚拟手柄输出仍需要现有的 USBIP 驱动安装流程。

本轮只调整连接界面与展示属性，不改变输入、陀螺仪、震动、校准和休眠协议。验证使用离线协议回放、四槽位 UI 操作、窄窗口截图与 EXE 启动检查；不把界面预览当作真实手柄测试。

验证结果：929403 项离线断言通过；原生 EXE 启动检查退出码 0、`UI_LOADED=true`，未启动游戏输出。默认首页、66Hz 提示和窄窗口截图已检查。
