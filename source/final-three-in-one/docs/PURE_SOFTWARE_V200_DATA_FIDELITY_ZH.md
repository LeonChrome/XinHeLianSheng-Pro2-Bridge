# PRO2 手柄助手 v2.0

继续支持 Windows 10 2004 及以上 / Windows 11 x64，保留 Steam / Pro2、Pro1、Xbox、PS5 四种模式。无需另装 .NET；首次使用仍可能需要安装内置 USBIP 驱动。

## 本次修复

- 输入：保护 USB 后端中的按下、松开边沿；修复高速 USB 周期解释；不再把缓存报告当成新输入。主机卡顿时丢弃超过 100ms 的旧历史、保留最新状态，不在恢复后补播过期按键。
- 体感：区分真实采样与协议重采样时钟；PS5 无效加速度保持本次会话最后有效重力，无效陀螺仪归零。
- 摇杆：修正 Pro1 输出校准范围，移除输出端额外的中心吸附；保留真实手柄校准和原有防漂移。
- 震动：普通 Xbox / PS5 震动保持、停止与切换保护；原始事件、生成刷新、安全停止分别计数。
- 诊断：分别记录真实输入、USB 报告、新样本、重复、合并、溢出和震动写入结果，日志达到容量后仍保留关键汇总。

## 速率说明

首页 FD2 始终表示真实 BLE 输入，不包含虚拟 USB 重复。

Pro2 有线协议兼容输出使用 4ms 零阶保持重采样，以适配接收端固定节拍标定；重复报告不代表新的物理采样。物理源长时间不更新时，停止保持非零角速度，并进一步释放控制，恢复新输入后自动恢复。

其他模式采用源节拍报告；为旧客户端显式保留的固定节拍兼容路径另行计数。目标是真实 133Hz，达到 60Hz 可兼容游玩；本次没有修改蓝牙参数、优化授权或电量策略，不保证所有硬件达到 133Hz。

## 必须保留的边界

- Xbox 模式模拟 Xbox 360，不提供原生陀螺仪。
- PS5 标准摇杆为 8bit，加速度当前标准量程约 ±4g；不同协议间存在量化和饱和。
- 普通双马达反馈不包含完整 HD 频谱；PS5 触觉 PCM 仍是有损频谱近似，不等于马达物理波形完全一致。
- 有界队列过载仍可能合并或丢弃数据，会记录计数；不能承诺任何负载下零丢失。
- 自动测试通过不代替实体三轴转动、具体游戏、长震动时长和不同蓝牙硬件验收。
- 后端 `source_unique` 统计上游新状态，可能包含背键动作或安全释放，不直接等于物理 FD2；首页 FD2 有独立测量。

## 更新方式

从旧版系统托盘退出后，再打开 v2.0；不要同时运行。原设置继续沿用，旧 EXE 保留可回退。本次连同 Go 后端重新编译并嵌入，不是仅修改版本号。

验证结果与下载校验见[发布说明](../../../docs/RELEASE_v2.0_ZH.md)；对应后端源码和许可证随 Release 提供。
