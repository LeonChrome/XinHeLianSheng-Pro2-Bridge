# v2.3：游戏按键图标

在“设置 → 游戏按键图标 → 管理游戏图标”中安装、更新或恢复。

当前适配《影之刃零》Steam 版。保持 PS5 模式，面键按实际位置显示 Pro2：上 X、右 A、下 B、左 Y。包含五套提示资源中的面键、肩键、扳机、摇杆按下、加减号和截图图标。触摸板方向手势和整张手柄示意图保留。

自动读取 Steam 安装位置与多个游戏库，支持不同盘符、中文和空格路径；找不到时可手动选择目录。Win10 / Win11 使用相同的文件补丁机制，与蓝牙型号无关。

安装前检查游戏内容版本与补丁哈希。游戏运行时不修改文件；目录需要权限时才请求管理员授权。游戏版本未适配时不安装，已有补丁仍可还原。

只添加三个独立补丁文件，不覆盖游戏 EXE、原资源包或存档。已知旧版补丁可备份后更新；文件被其他内容修改时停止操作，不强行覆盖或删除。操作记录与备份保存在用户本地数据目录。

此功能按游戏分别适配，并非所有 Steam 游戏的通用图标替换。它不改变助手的 BLE、按键映射、陀螺仪或触觉链路；自定义背键/C 键不动态改变游戏提示。
