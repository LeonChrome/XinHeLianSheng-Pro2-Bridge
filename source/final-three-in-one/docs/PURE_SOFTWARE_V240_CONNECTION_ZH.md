# v2.4：缩短连接等待

自动连接发现可信 Pro2 广播后可提前结束扫描：优先上次连接地址，Nintendo 厂商信息与明确的 Pro2 名称同时匹配也可触发。首次连接没有足够身份信息时继续完整扫描，不因同为 Nintendo 设备就提前锁定。手动列表和独立扫描保留完整收集窗口。

Windows 断线事件直接唤醒重连守护，减少等待下一次轮询的时间。仍保留 2 秒输入中断保护和连续失败退避；不缩短初始化、GATT 身份检查、电量读取或真实 FD2 速率验收。

日志新增 `PRO2_DISCOVERY_TIMING`、`PRO2_CONNECT_TIMING`、`PRO2_RECONNECT_TIMING`，区分发现、BLE 就绪、游戏输出就绪和 Windows 观察到断线后的恢复时间。它们不代表从手柄实体电源按下到响应的总延迟。

旧版六次成功连接的日志中，扫描约 8.17 秒，发现候选后仍等 4.26～5.79 秒，BLE 就绪约 12.19 秒。该数据用于定位改动，不是新版实机提速承诺；新版耗时以连接日志为准。

保留 v2.3 的《影之刃零》图标管理：多 Steam 库自动发现、目录手选、版本校验、旧补丁更新和恢复。只处理独立补丁，不覆盖游戏 EXE、主资源包或存档。触摸板方向手势、整张手柄图和自定义映射的动态图标不在覆盖范围。
