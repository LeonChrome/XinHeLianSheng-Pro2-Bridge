# PRO2 手柄助手 v3.4.1 · 蓝牙转发

3.4.1 修复发射器启动时的本机 UDP 10054 误停：原生后端确认端口就绪后，主程序才发送心跳。准备前记录驱动状态与故障码；对所选适配器的错误 10/43，备份后最多尝试一次重启。恢复驱动也检查持续健康状态，避免刚启动就误报恢复成功。准备失败原因会在释放输入前写入日志，界面保留报错与本轮日志入口。

当前转发端的配对密钥只保留在本次进程内存中。重开转发后若接收设备连接失败，请在接收端忘记旧的 Pro Controller，再重新配对。

原有的本机 Pro2、Pro1、Xbox、PS5 输出继续使用。首页新增“蓝牙转发”，将 USB 连接的 Pro2 / Pro1 转发给其他设备，外发身份为 Pro Controller（Pro1）。当前没有 PS5 / Xbox 蓝牙外发。

1. USB 数据线连接实体手柄，首页打开“蓝牙转发”。程序先暂停本机虚拟输出和自动重连，释放实体输入。
2. 选择 USB 手柄与蓝牙适配器。多个适配器时必须手动选择，只接管选中的精确设备实例；拔掉它后不会自动换用其他适配器。
3. 默认请求 133Hz，也可选择标准 66.7Hz 或 250Hz。点击“准备并开始无线”，按 Windows 要求批准管理员授权。
4. 接收设备搜索并连接 Pro Controller。转发持续到手动停止，不会因为三分钟实验时限主动断开。
5. 停止或关闭转发窗口后恢复由本工具临时切换的蓝牙驱动。退出后可重新在本机连接手柄游玩。

单个 EXE 已内置转发后端、匹配运行固件、驱动准备脚本与许可文件，无需另外打开实验程序。程序不会自动下载驱动、关闭签名验证或导入配对密钥。没有本机已经信任的对应 WinUSB 包时，会说明原因并停止；此版本不是通用蓝牙驱动安装器。

目前支持的原生发射器为 Realtek 0BDA:0852 与 Actions 10D7:B012。其他蓝牙会显示为未支持，不会被改绑。所选适配器原有的 Windows 蓝牙连接（耳机、键鼠等）会临时中断。只有一只蓝牙也可外发，因为实体手柄使用 USB 输入。

原驱动备份：`%LOCALAPPDATA%\PRO2WirelessReceiverControlBoard\radio\时间戳\`。恢复失败时使用窗口“恢复系统蓝牙”，或对应备份目录的 `Restore-Bluetooth.cmd`。会核对系统与设备，不覆盖其他程序后来更改的驱动。

日志：`%LOCALAPPDATA%\PRO2WirelessReceiverControlBoard\wireless_relay_logs\时间戳\`。单列 USB 实体输入、蓝牙提交、HCI 完成回执、覆盖计数、主机命令及驱动恢复结果。提交频率不是接收端真实频率。原生间隙详细样本有固定容量，长时间运行时只代表已保留的前段样本；累计计数与连接总时长另外保存。

Pro2 USB 可读 amiibo 并提供只读快照，也可载入 540 / 572 字节文件；读取后移走卡片不会自动撤回快照，使用“移除标签快照”。不写卡，不验证真实性。Pro1 USB 不支持实体读卡，可载入已有文件。

已有实测：USB 输入约 250Hz，外部设备确认摇杆和按键响应，一轮连接 60 秒无意外断开，原驱动自动恢复。本版整合后由用户继续验收；未额外实机联测。不能据此承诺端到端 133/250Hz、震动/体感效果或接收端 amiibo 兼容性。
