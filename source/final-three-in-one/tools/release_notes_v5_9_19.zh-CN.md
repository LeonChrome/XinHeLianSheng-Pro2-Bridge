# V5.9.19 按键边沿、macOS 与模式稳定版

本版本基于 GitHub `v5.9.17`，集中修复输入边沿、macOS 识别和刷机后模式显示漂移。

## 修复内容

- BLE 通知短暂间隙不再注入“全松开”状态。
- 按住按键时保留最后真实状态；只有 BLE 明确断开、协议栈复位或主动恢复链路时才释放全部按键。
- 修复由虚假“松开 → 再按下”边沿造成的单击变双击、持续按键重复触发和菜单快速开关。
- 新增 `macOS / 标准 HID` 固件，使用标准 USB HID Gamepad 描述符，USB 身份为 `CAFE:4037`，不依赖 Windows XInput 驱动。
- Xbox 固件继续保留 `045E:028E` XInput 身份；Pro2 / Nintendo 固件继续保留 `057E:2069` 身份。
- 所有发布固件继续使用编译期模式锁，运行时配置不能把 Xbox、Nintendo 或 macOS 固件改成另一种 USB 身份。
- 管理器刷写完成后不再重复写入模式并二次重启。
- 等待新 USB 枚举期间，旧 USB 描述符不会与新固件串口身份互相覆盖。
- USB 检测只统计当前实际存在且无错误的 PnP 设备；“未检测到设备”提示文字不再被误判成 XInput。

## 使用提示

1. Windows 游戏优先使用 Xbox / XInput、PS5 或 Pro2 / Nintendo 固件。
2. macOS 请刷入 `macOS / 标准 HID`，刷完后重新插拔原生 USB / OTG 数据线。
3. 模式切换后不需要再次发送串口 `mode` 命令。
4. 如果原生 USB 仍显示旧身份，请物理重新插拔一次；管理器会保持“等待验证”，不会在 Xbox 与 Nintendo 面板间来回跳动。

## 验证

- ESP32-S3 五个桥接配置均独立编译并锁定模式。
- Windows 管理器完成 Release 构建和内置包自检。
- 静态回归检查覆盖：按键状态保持、显式断开释放、macOS HID 描述符、刷后不重写模式、PnP 实际存在过滤。
