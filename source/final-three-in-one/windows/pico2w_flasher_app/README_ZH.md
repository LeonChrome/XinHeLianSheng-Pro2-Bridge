# 新和联胜 Pico 2 W 一键刷机工具

此工具面向已经装入背挂外壳的 Raspberry Pi Pico 2 W。Windows 10/11 x64 用户无需安装驱动、Pico SDK 或构建环境，EXE 内置唯一的 r40 候选 UF2。

## 使用方法

1. 从 Pico 端断开真实 Pro2，并关闭背挂电池电源。
2. 只用 Pico 的电脑 USB 连接 Windows。
3. 若工具显示调试串口，点击“让已连接的 Pico 自动进入 BOOTSEL”。
4. 若旧固件不支持自动进入，按住 Pico 的 `BOOTSEL`，插入电脑 USB 后松开。
5. 工具识别到 `RP2350` 磁盘后，点击“开始刷入内置固件”。
6. 等待 `firmware_revision=r40` 与 `runtime_ready=true` 都验证通过，再拔线恢复背挂供电。

## 配对与重连

- 切换到一个从未配对过的模式后，固件会持续开放配对，不设置一分钟之类的自动关闭时间。
- 已保存主机时，当前模式先进行一次快速主动回连；若主机没有响应，约 6.5 秒后回到 30 秒连续可发现窗口，再低频尝试旧主机。不会再用 6 秒高频循环反复关闭可发现状态。
- 若 Windows 已删除设备而 Pico 仍保存旧密钥，固件会在主机重新索要 PIN 时判定密钥失配，只清除当前身份的旧密钥并立即重新开放配对。
- Windows 正常应通过 SSP Just Works 直接完成 PS5 / Edge 配对。若旧蓝牙适配器或驱动仍弹出 PIN，当前固件的兼容密码固定为 `0000`，不要输入 `1234`；r40 会在日志中记录双方 SSP 能力与回退原因。
- 任一时刻只有当前模式的一套无线后端和一个活动主机。另一台电脑或 Steam 中残留同名设备，只表示系统保存过身份，不代表 Pico 正在向两台主机同时发送输入。
- 要换设备，长按 Pro2 的 `GL + GR + ZL + ZR + Plus + Minus` 2 秒。Pro2 轻微低频震动两下后，当前模式旧记录被清除并重新开放配对。
- 该动作只清除当前模式，不影响另外三种无线身份保存的主机。
- 各平台详细步骤见同目录 `PLATFORM_PAIRING_ZH.md`。

## 安全约束

- 只接受 RP2350 / Pico 2 W，不允许向 Pico 1 / RP2040 写入。
- EXE 启动时校验内置 UF2 的 SHA256、UF2 魔数、块序号和 family ID。
- 固件写入范围必须避开闪存末端 10 个扇区，因此不会主动覆盖上次模式和四种无线身份的蓝牙绑定资料。
- 检测到多个 RP2350 时拒绝刷入，避免选错开发板。
- 同时检测到 BOOTSEL 磁盘和另一块运行中的 Pico 时拒绝刷入，避免刷后验证到错误设备。
- 写入按钮在操作期间锁定，不能重复点击。
- 日志每次运行只保留当前文件，最大 1 MiB。

## 能力边界

- Xbox 模式按协议不提供陀螺仪。
- Xbox BLE 模式适用于 Windows、Android 和 Apple 蓝牙设备，不能连接使用 Xbox Wireless 协议的 Xbox 主机。
- PS5 / Edge 模式可供兼容的 PC、Android 和 Apple 应用识别，但当前不能完成实体 PS5 主机要求的 USB 首次配对与认证。
- PS5 / PS5 Edge 不模拟 DualSense 音频设备，因此不提供音频流 HD haptic、耳机或麦克风。
- PS5、PS5 Edge、Xbox 和 NS1 Pro 均把可用的主机震动降级/转换为 Pro2 普通双通道震动。
- Pro2 原生/静默模式需要背挂硬件用 `GP3` 控制 Pro2 口的 5 V 负载开关。若 Type-C 的 VBUS 红线直接接常通 5 V，固件只能释放数据线，不能实现真正的物理断开。
- r40 继承 r39 的 USB Host 输入源分级恢复、单活动主机、摇杆满量程、失配密钥恢复与 SSP Just Works 配对，产品默认模式仍为 PS5 Edge。
- r40 保留 PS5 / Edge 兼容马达的显式停振状态机。主机撤销普通马达有效位后，Pico 会立即向 Pro2 发送停止命令，不再把灯光或模式报文误当成“继续保持上一次震动”。
- r40 的 NS1 Pro 先按真实手柄使用 `0x3F` 简单输入报告连接，收到主机 `0x03` 子命令后才进入 `0x30` 完整报告；按真实 Switch Pro 布局修正按键与方向帽，并补齐设备信息、运行时间及 NFC/IR 子命令回复。
- r40 为 NS1 握手增加四槽回复队列，避免主机连续查询校准数据时前一条回复被覆盖；切换身份、主机断开和无线重启前仍会统一停止实体 Pro2 震动。
- PS5、Edge、Xbox 和 NS1 Pro 共用中心 `2048`、死区 `64`、中心至满量程 `1600` 的物理归一化，不增加移动平均、缓动或速度补偿。
- `imu status` 会同时打印实时 Pro2 原始六轴值与最终 DualSense 六轴值，便于直接区分传感器源、坐标转换和主机解析问题。

## 常见问题

- **Windows 显示未知发布者**：当前候选 EXE 尚未使用商业代码签名证书。正式公开分发前建议完成 Authenticode 签名；测试时先用同目录 `SHA256SUMS.txt` 核对文件完整性。
- **看不到开发板**：确认电脑数据线接的是 Pico 自身 USB，不是 Pro2 的 Type-C；关闭背挂电池，再手动进入 BOOTSEL。
- **只看到 RPI-RP2**：这是 Pico 1 / RP2040，不兼容本固件。
- **自动进入失败**：可能是旧固件不支持 `bootsel`、串口被监视器占用，或 USB 线只有供电；改用手动 BOOTSEL。
- **UF2 写完但验证失败**：重新插拔 Pico 的电脑 USB，再运行工具检测。工具会等待自检、CYW43 无线芯片和当前模式后端全部就绪；不要仅凭 RP2350 磁盘消失判断成功。
- **Pro2 黄灯静置后熄灭**：黄灯是充电/活动提示，不是 USB 输入链路指示。以 `USB_HEALTH connected=1 ... reports=1` 和持续增长的 `parsed` 为准。
- **另一台电脑仍显示旧控制器**：先在那台电脑的蓝牙和 Steam 中删除旧记录。固件的 `wireless status` 会显示 `max_active_hosts=1 simultaneous_multi_mode=off`。
